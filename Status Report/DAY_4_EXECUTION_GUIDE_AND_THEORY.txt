1. PREREQUISITE THEORY & CONCEPTUAL KNOWLEDGE
================================================================================

To effectively execute and debug Day 4 tasks, team members must understand the 
following theoretical and practical software engineering domains:

1.1 RESTful API Architecture & HTTP Contract Protocols:
-------------------------------------------------------
- HTTP Methods & Semantics:
  * GET: Idempotent & safe resource retrieval (e.g., /api/status, /api/seats).
  * POST: State-changing, non-idempotent operations (e.g., /api/scan, /api/reset).
- HTTP Status Codes:
  * 200 OK: Successful query or status update.
  * 201 Created: New student automatically registered on first scan.
  * 400 Bad Request: Missing payload parameters (e.g., missing studentId) or 
    business logic violations (duplicate scan within 5s cooldown).
  * 404 Not Found: Entity lookup failure (e.g., /api/student/NONEXISTENT).
  * 500 Internal Server Error: Database failure or unhandled exception.

1.2 Automated Integration Testing with Jest & Supertest:
--------------------------------------------------------
- Supertest: Creates ephemeral HTTP agents wrapping Express 'app' without 
  binding to physical network ports, speeding up test execution.
- Jest Lifecycle Hooks:
  * beforeAll(): Initializes DB connection and configuration before any tests run.
  * afterAll(): Closes open handles, database connections, and background timers.
- Asynchronous Testing Patterns:
  * Using async/await with Supertest assertions.
  * Controlling execution flow during cooldown periods (e.g., awaiting sleep 
    delay of 5100ms for duplicate throttling tests).
  * Setting appropriate Jest test timeouts: jest.setTimeout(15000) for slow 
    network/timer tests.

1.3 State Machine Theory & Odd/Even Scan Counting:
--------------------------------------------------
- Deterministic State Transitions:
  * Initial State: scan_count = 0 (or even) -> Next Action = ENTRY -> New Status = INSIDE.
  * Next State: scan_count = 1 (or odd)  -> Next Action = EXIT  -> New Status = OUTSIDE.
- Mathematical Invariant:
  * Action = (scan_count % 2 === 0) ? 'ENTRY' : 'EXIT'
  * NewStatus = (scan_count % 2 === 0) ? 'INSIDE' : 'OUTSIDE'
- Testing Objective: Verify state transitions happen sequentially and atomically.

1.4 Concurrency, Throttling & Hardware Debounce Theory:
------------------------------------------------------
- Physical RFID/Barcode Scanners can emit duplicate keystrokes/signals in rapid 
  succession (bounce effect).
- Cooldown Throttle Window: 5000 milliseconds (5 seconds).
- Algorithm:
  timeDelta = Date.now() - new Date(lastScan.timestamp).getTime();
  if (timeDelta < 5000) reject with 400 "Duplicate scan detected".
- Testing Objective: Validate that scans at t = 0s succeed, scans at t = 1s fail 
  with 400, and scans at t = 5.2s succeed as EXIT.

1.5 Boundary Value Analysis (BVA) & Defensive Programming:
----------------------------------------------------------
- Zero-Floor Boundary: Library occupied_seats must never decrement below 0, even 
  if an exit scan is processed when occupied_seats is already 0:
  newCount = Math.max(0, currentSeats - 1)
- Ceiling/Capacity Boundary: If occupied_seats exceeds total_seats, the system 
  must handle over-capacity gracefully and log administrative warnings.
- Date Expiry Boundary: ISO 8601 string parsing (YYYY-MM-DD) comparing against 
  midnight UTC to prevent timezone skew.

1.6 CI/CD Pipeline Secret Handling & Smoke Test Fallback:
--------------------------------------------------------
- Dual-Mode Pipeline Design:
  * Mode A (Full Integration): When SUPABASE_URL and SUPABASE_SERVICE_KEY secrets 
    are present in GitHub Secrets, execute the complete test suite.
  * Mode B (Smoke Test Fallback): If repository secrets are absent (e.g. in 
    forked PRs), execute 'src/tests/simple.test.ts' so CI builds do not fail 
    falsely.

Below is the concrete implementation structure for backend/src/tests/library.test.ts:

```typescript
import request from 'supertest';
import app from '../server';
import { initializeDatabase } from '../config/database';
import { isAccessExpired } from '../utils/access_expiry';
import { updateOccupiedSeats } from '../models/library.model';

describe('Smart Library Comprehensive API Test Suite', () => {
  const testStudentId = `TEST_MGK_${Date.now()}`;

  beforeAll(async () => {
    await initializeDatabase();
  });

  // 1. Health & Status Checks
  describe('GET /api/health', () => {
    it('should return 200 and healthy status', async () => {
      const res = await request(app).get('/api/health');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.status).toBe('healthy');
      expect(res.body).toHaveProperty('uptime');
    });
  });

  describe('GET /api/status', () => {
    it('should return library occupancy status metrics', async () => {
      const res = await request(app).get('/api/status');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.data).toHaveProperty('totalSeats');
      expect(res.body.data).toHaveProperty('occupiedSeats');
      expect(res.body.data).toHaveProperty('availableSeats');
      expect(res.body.data).toHaveProperty('occupancyRate');
    });
  });

  // 2. Scan Operations & Throttling
  describe('POST /api/scan', () => {
    it('should reject scan if studentId is missing (400 Bad Request)', async () => {
      const res = await request(app).post('/api/scan').send({});
      expect(res.status).toBe(400);
      expect(res.body.success).toBe(false);
      expect(res.body.error).toMatch(/Student ID is required/i);
    });

    it('should process ENTRY scan and auto-create new student', async () => {
      const res = await request(app)
        .post('/api/scan')
        .send({ studentId: testStudentId });

      expect([200, 201]).toContain(res.status);
      expect(res.body.success).toBe(true);
      expect(res.body.action).toBe('ENTRY');
      expect(res.body.student.id).toBe(testStudentId);
      expect(res.body.student.status).toBe('INSIDE');
      expect(res.body.libraryStatus).toHaveProperty('totalSeats');
      expect(res.body.libraryStatus).toHaveProperty('occupiedSeats');
    });

    it('should reject duplicate scan within 5s cooldown window', async () => {
      const res = await request(app)
        .post('/api/scan')
        .send({ studentId: testStudentId });

      expect(res.status).toBe(400);
      expect(res.body.success).toBe(false);
      expect(res.body.error).toMatch(/Duplicate scan detected/i);
    });

    it('should process EXIT scan after cooldown period', async () => {
      // Wait for 5.1 seconds cooldown
      await new Promise((resolve) => setTimeout(resolve, 5100));

      const res = await request(app)
        .post('/api/scan')
        .send({ studentId: testStudentId });

      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.action).toBe('EXIT');
      expect(res.body.student.id).toBe(testStudentId);
      expect(res.body.student.status).toBe('OUTSIDE');
    }, 15000);
  });

  // 3. Student Details & Access Validation
  describe('GET /api/student/:studentId', () => {
    it('should return 404 for non-existent student', async () => {
      const res = await request(app).get('/api/student/NONEXISTENT_99999');
      expect(res.status).toBe(404);
      expect(res.body.success).toBe(false);
      expect(res.body.error).toMatch(/Student not found/i);
    });

    it('should return 200 with student profile for existing student', async () => {
      const res = await request(app).get(`/api/student/${testStudentId}`);
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.data.id).toBe(testStudentId);
      expect(res.body.data).toHaveProperty('name');
      expect(res.body.data).toHaveProperty('current_status');
    });

    it('should correctly evaluate date expiry in isAccessExpired utility', () => {
      expect(isAccessExpired('2000-01-01')).toBe(true);
      expect(isAccessExpired('2099-12-31')).toBe(false);
      expect(isAccessExpired('invalid-date-string')).toBe(false);
    });
  });

  // 4. Seat Map & Pictograph
  describe('GET /api/seats', () => {
    it('should return seat map 2D matrix structure', async () => {
      const res = await request(app).get('/api/seats');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.data).toHaveProperty('seats');
      expect(res.body.data).toHaveProperty('totalSeats');
      expect(res.body.data).toHaveProperty('occupiedSeats');
      expect(res.body.data).toHaveProperty('availableSeats');
      expect(res.body.data).toHaveProperty('occupancyRate');
      expect(Array.isArray(res.body.data.seats)).toBe(true);

      if (res.body.data.seats.length > 0) {
        const firstSeat = res.body.data.seats[0][0];
        expect(firstSeat).toHaveProperty('id');
        expect(firstSeat).toHaveProperty('row');
        expect(firstSeat).toHaveProperty('col');
        expect(firstSeat).toHaveProperty('status');
      }
    });
  });

  // 5. Scan Logs & Students Inside
  describe('GET /api/scan-logs & GET /api/students-inside', () => {
    it('should return scan logs array', async () => {
      const res = await request(app).get('/api/scan-logs?limit=5');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(Array.isArray(res.body.data)).toBe(true);
    });

    it('should return students currently inside', async () => {
      const res = await request(app).get('/api/students-inside');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(Array.isArray(res.body.data)).toBe(true);
      expect(typeof res.body.count).toBe('number');
    });
  });

  // 6. Administrative Reset & Boundary Guards
  describe('POST /api/reset', () => {
    it('should reset library occupancy and set all students to OUTSIDE', async () => {
      const res = await request(app).post('/api/reset');
      expect(res.status).toBe(200);
      expect(res.body.success).toBe(true);
      expect(res.body.message).toMatch(/reset/i);

      // Verify status is zeroed
      const statusRes = await request(app).get('/api/status');
      expect(statusRes.body.data.occupiedSeats).toBe(0);
    });

    it('should prevent occupied_seats from decrementing below zero', async () => {
      const result = await updateOccupiedSeats(false);
      expect(result).toBe(true);

      const statusRes = await request(app).get('/api/status');
      expect(statusRes.body.data.occupiedSeats).toBe(0);
    });
  });
});
```
